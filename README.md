## راه‌اندازی محلی

```bash
cd stationery_bot
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

# فایل .env بسازید
cp .env.example .env
# BOT_TOKEN را داخل .env بگذارید

# ایمپورت اولیه اکسل (اختیاری)
python import_excel.py

# اجرا
python main.py
```

## دیپلوی روی Railway

1. یک پروژه جدید در Railway بسازید و این پوشه را به GitHub وصل کنید (یا مستقیم آپلود کنید).
2. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN` = توکن بات
   - `WEBAPP_URL` = آدرس دامنه Railway شما (مثال: `https://stationery-bot-production.up.railway.app`)
   - `PORT` معمولاً خودکار تنظیم می‌شود.
3. بعد از دیپلوی، آدرس `WEBAPP_URL` را در متغیرها دقیق بگذارید و یک بار Redeploy کنید.
4. در @BotFather دستور `/setmenubutton` یا از داخل بات دکمه مینی‌اپ را تست کنید.
5. برای دامنه مینی‌اپ، در BotFather بخش Domain را روی دامنه Railway تنظیم کنید (Bot Settings → Domain).

## نکات مهم مینی‌اپ
- مینی‌اپ فقط روی اپلیکیشن موبایل تلگرام (Android/iOS) دوربین را باز می‌کند.
- روی نسخه وب تلگرام اسکنر کار نمی‌کند.
- بعد از اسکن موفق، بارکد به بات ارسال و محصول نمایش داده می‌شود.
