## دیپلوی روی Railway

1. یک پروژه جدید در Railway بسازید و این پوشه را به GitHub وصل کنید (یا مستقیم آپلود کنید).
2. متغیرهای محیطی را تنظیم کنید:
   - `BOT_TOKEN` = توکن بات
   - `WEBAPP_URL` = آدرس دامنه Railway شما (مثال: `https://stationery-bot-production.up.railway.app`)
   - `PORT` معمولاً خودکار تنظیم می‌شود.
3. بعد از دیپلوی، آدرس `WEBAPP_URL` را در متغیرها دقیق بگذارید و یک بار Redeploy کنید.
4. در @BotFather دستور `/setmenubutton` یا از داخل بات دکمه مینی‌اپ را تست کنید.
5. برای دامنه مینی‌اپ، در BotFather بخش Domain را روی دامنه Railway تنظیم کنید (Bot Settings → Domain).
6. ⚠️ **حیاتی:** یک Volume دائمی در Railway بسازید (Settings → Volumes) و آن را به مسیری مثل
   `/data` وصل کنید، بعد متغیر `DATABASE_PATH` را روی `/data/products.db` بگذارید. بدون این
   کار، دیتابیس روی فضای موقت ذخیره می‌شود و با هر ری‌استارت یا دیپلوی جدید پاک می‌شود.

## گرفتن آیدی عددی ادمین (امن‌تر از یوزرنیم)
یوزرنیم تلگرام قابل تغییره؛ برای امنیت بیشتر بعد از دیپلوی، هر دو ادمین باید یک بار داخل
بات دستور `/myid` (یا دکمه «🆔 آیدی من») را بزنند و عدد نمایش‌داده‌شده را داخل
`ADMIN_IDS` در `config.py` قرار بدهند.

## نکات مهم مینی‌اپ
- مینی‌اپ فقط روی اپلیکیشن موبایل تلگرام (Android/iOS) دوربین را باز می‌کند.
- روی نسخه وب تلگرام اسکنر کار نمی‌کند.
- بعد از اسکن موفق، بارکد به بات ارسال و محصول نمایش داده می‌شود.

## ساختار دیتابیس
فیلدها: دسته، خصوصیت ۱–۵، برند، نام کامل، قیمت خرید/فروش/عمده، موجودی، بارکد، فروشنده، کد فروشنده، عکس (file_id تلگرام)

## ادمین‌ها
در فایل `config.py` لیست `ADMINS` را می‌توانید تغییر دهید.
برای امنیت بیشتر User ID عددی را در `ADMIN_IDS` اضافه کنید (به بخش «گرفتن آیدی عددی» بالا نگاه کنید).

## ایمپورت اکسل از داخل خود بات
گزینه‌ی «📥 ایمپورت اکسل» در پنل مدیریت **دیگر داده‌ها را پاک نمی‌کند**. برای هر ردیف
اکسل، اگر کالایی با همان دسته/خصوصیت/برند از قبل وجود داشته باشد فقط قیمت‌هایش به‌روز
می‌شود و بارکد، موجودی و عکسِ ثبت‌شده قبلی دست‌نخورده می‌ماند (مگر این‌که اکسل خودش
ستون بارکد یا موجودی داشته باشد که در آن صورت مقدار اکسل جایگزین می‌شود). کالاهای جدید
هم اضافه می‌شوند.
